## How to Apply These Changes

### Update descriptions (via GitHub web):
1. Go to each repo on GitHub
2. Click the gear icon next to "About" (top right)
3. Update the description and add topics

### Rename repos (via GitHub web):
1. Go to repo Settings
2. Change the Repository name
3. GitHub auto-redirects old URLs

### Pin repos:
1. Go to your profile (github.com/MORAWA-dev)
2. Click "Customize your pins"
3. Select the 6 repos listed above

### Archive old/completed repos:
1. Go to repo Settings
2. Scroll to "Danger Zone"
3. Click "Archive this repository"

Suggested archives: `hello-git`, `git-journey`, `html-portfolio`, `project-making-flag-of-burkina`
